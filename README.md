# IoT-Based Real-Time Electrical Parameters Monitoring System Using ESP32 & PZEM-004T

## Overview
This project is an IoT-based real-time electrical parameter monitoring system developed using ESP32 and PZEM-004T energy meter module. The system continuously measures and displays important electrical parameters such as Voltage, Current, Power, Energy Consumption, Frequency, and Power Factor.

Measured data is shown simultaneously on:
- Local Web Server Dashboard
- OLED Display

The ESP32 hosts a wireless web interface, allowing users to monitor live electrical data from any device connected to the same Wi-Fi network.
